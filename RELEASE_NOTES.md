# Source snapshot notes

This repository presents selected historical source code with project documentation. Models and private dependencies are not bundled, and the three pipelines have not been rerun as part of this release.

Machine-specific paths were replaced with `/path/to/local_asset` placeholders. Existing author and third-party license notices are retained. The parcel project contains the SlowFast training snapshot; the separate TorchServe service archive is not part of this snapshot.
